Setup

Connect ElevenLabs

Your voice library, right in your browser.

  1. Create an API key in ElevenLabs ↗
  2. Keep Restrict Key on. Enable these permissions:
    Text to Speech
    Access
    Voices
    Read
    Models
    Read
  3. Copy the secret key shown when you create it. A key name or Key ID will not work.

No User access or write permissions needed. Connecting checks voices and models without generating speech.

Reading uses your ElevenLabs credits. You can set a credit cap on this key. The extension itself is free.

Select text on a page, then press Read selection.

Reading uses credits. Voice previews do not generate speech.
